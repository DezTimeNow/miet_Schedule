# Идея: мини-игра «Тапать микросхему» с общим топом

Дата: 2026-10-03
Статус: отложено, по решению БОССа. Реализация не начата.

## Суть

Внутри приложения — мини-игра. Игрок тапает по микросхеме, каждое нажатие
даёт +1 очко. Очки публикуются в общий недельный топ: игрок вводит ник
(до 30 символов) и отправляет результат. Цель — попасть в топ повыше,
чтобы имя было видно. Каждый понедельник в 9:00 топ сбрасывается в ноль.

## Что хочет БОСС

- Кнопка с игрой в главном меню (рядом с выбором роли).
- Возможность написать в чат/топ любой текст до 30 символов.
- Конкуренция: игроки подначивают друг друга, чтобы их ник был выше.
- Топ живёт на сервере, а не на устройстве.
- Сброс по расписанию: понедельник 09:00.

## Заготовка интерфейса (не свёрстана, для будущей проработки)

- `ChipTapGame.kt` — экран игры: тап по микросхеме, счёт, поле ника, кнопка «В топ».
- `ChipTapLeaderboard.kt` — список лидеров (место, ник, очки).
- Ник ограничен 30 символами на вводе, длиннее — отсекается.

## Главное техническое препятствие

Топ требует общего сервера. Локальный сервер внутри приложения для этого
не годится: список не будет общим между устройствами — он живёт только
в памяти одного телефона.

Что это значит для выбора вариантов:

- Вариант A — свой сервер. Нужен домен/хостинг, API для приёма и выдачи
  топа, защита от накрутки. Основная работа и постоянные расходы.
- Вариант B — бесплатный хостинг (Firebase, Supabase, бесплатный tier
  облака). Быстрее всего для прототипа, но внешняя зависимость.
- Вариант C — GitHub Issues/gist как «база». Только для прототипа, не
  для продакшена: нет гарантии доступа и есть задержка.

## Что нужно решить до реализации

1. Где живёт топ: свой сервер или готовый сервис.
2. Можно ли доверять очкам с клиента. Наивная отправка `score` позволяет
   накрутить любое число — потребуется либо серверная проверка, либо
   ограничение по частоте запросов.
3. Анонимность: ника нет проверки, любой текст до 30 символов. Нужно
   понять модерацию или её отсутствие.
4. Точное время сброса: 9:00 в каком часовом поясе. Сервер или локально.
5. Экономика: игра с топом — это рекламный и удерживающий элемент,
   а не источник дохода. Оправдано ли вложение в сервер.

## Риск к оценке

Топ без начального наполнения выглядит пусто: при нуле игроков иконка в
главном меню не приносит пользы и занимает место. Стоит проверить на
реальном круге людей, открывает ли он приложение чаще, до вложения в сервер.
