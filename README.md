# Расписание МИЭТ

Android-приложение для просмотра расписания занятий МИЭТ.

ВНИМАНИЕ! Приложение 100% **агентный вайбкод**, как это работает не понимает даже разработчик!!! Съедено более 900м токенов

## Статус

Проект в стадии **альфы**: функциональность может измениться без
предупреждения, обратная совместимость не гарантируется.


## Возможности

Три роли, каждая открывает свой набор данных:

- **Студент** — расписание своей группы
- **Преподаватель** — расписание преподавателя, собирается по всем группам
- **Аудитория** — кто и когда занимает помещение

Расписание показывается по дням с указанием даты, с переключением учебных недель
и фильтром на сегодняшний день.

## Установка

Актуальная сборка публикуется в разделе [Releases](https://github.com/DezTimeNow/miet_Schedule/releases/latest).

Приложение обновляется само: при запуске проверяется наличие новой версии,
при наличии предлагается скачать и установить.

Требуется Android 7.0 (API 24) или новее. **Установка из файла требует
разрешения на установку из неизвестных источников.**

## Технологии

- Kotlin, Jetpack Compose (Material 3)
- OkHttp для сетевых запросов, Gson для разбора JSON
- SharedPreferences для локального кэша
- AGP 8.7.3, Kotlin 2.0.21, Gradle 8.9
- minSdk 24, targetSdk 35

### Ключ подписи — критически важно

Ключ лежит **вне репозитория**: `~/.android/debug.keystore`, стандартный
отладочный, алиас `androiddebugkey`, пароли `android`.

**Потеря ключа означает невозможность выпустить обновление.** Android
сверяет сертификат при установке, поэтому APK с другим ключом не встанет
поверх уже установленного: система сочтёт его чужим приложением и потребует
сначала удалить старое. Избранное и другие данные при этом теряются.

Отсюда правило: **резервная копия ключа обязана существовать вне сервера.**
Хранить ключ в GitHub нельзя — репозиторий публичный.


## Источник данных

Приложение не хранит расписание само — оно читает его с сайта университета
и кэширует локально для офлайн-просмотра. Расписание преподавателя и аудитории
не отдаются сайтом напрямую и собираются из расписаний групп.

## Настройки

С главного экрана (выбор роли), под списком ролей: **Настройки** и **О программе**.

### Напоминания о парах

По умолчанию выключены. Включение запрашивает системное разрешение на уведомления
(Android 13+). Работают без интернета: расписание берётся из локального кэша,
поэтому уведомление приходит даже при выключенной сети.

Интервал выбирается из четырёх вариантов: **1, 5, 10, 15 минут** до начала пары.
Смена интервала сразу пересчитывает уже поставленные будильники.

Напоминания ставятся только для групп, отмеченных звёздочкой. После перезагрузки
устройства они восстанавливаются автоматически.

Точность: Android не даёт ставить точные будильники без отдельного разрешения, поэтому
используется `setAndAllowWhileIdle`. На активном экране задержка измеряется в секундах,
в режиме Doze Android растягивает интервал между обслуживанием до нескольких минут.
Пользователю об этом ничего не сообщается — в интерфейсе только факт «работает без
интернета».

### Оформление

**Как на системе / Светлая / Тёмная.** Выбор сохраняется и применяется сразу, без
перезапуска. Контраст текста проверен: не ниже WCAG AA.

### Актуальность данных

Расписание обновляется в фоне раз в 6 часов и при открытии. В шапке видно две разные
вещи: когда данные получены и когда приложение последний раз проверяло сайт — при
недоступной сети это сразу читается по подписи.
