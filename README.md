## Что умеет

- **Пары на сегодня** — весь день по порядку: предмет, аудитория, преподаватель, время. Прошедшие приглушены, идущая подсвечена, у будущих — отсчёт.
- **Расписание по группе, преподавателю или аудитории** — можно смотреть с любой стороны.
- **Избранное** — отметьте звёздами нужное, будет под рукой.
- **Напоминания** — за 1, 5, 10 или 15 минут до начала пары.
- **Работает без интернета** — расписание хранится на телефоне.

## Главный экран

Сверху — **пары на сегодня**: прошедшие приглушены, идущая подсвечена со временем до конца, у будущих — отсчёт до начала. Когда пары закончатся, покажется следующий день с занятиями.

Ниже — **избранное**: последние добавленные. Нажатие открывает расписание сразу. Кнопка **«Добавить»** — добавить новое.

## Вкладки

Внизу три вкладки: **Главная / Избранное / Настройки**. Они видны на любом экране.

### Избранное

![Избранное](docs/07-favorites.jpg)

Полный список всего, что отметили звёздами. Здесь же кнопка **«Добавить»** — можно добавлять прямо с этой вкладки.

### Настройки

![Настройки](docs/08-settings.jpg)

Напоминания о парах, оформление и раздел **«О программе»** — версия, проверка обновлений, кнопка «Сообщить об ошибке».

## Расписание

### Группа

Выбираете группу из 343 — и видите расписание по дням. Недели переключаются кнопками ‹ ›, приложение само показывает какую сейчас: «числитель», «знаменатель». Можно посмотреть всю неделю сразу.

![Расписание группы](docs/03-schedule.jpg)

### Преподаватель

Поиск по фамилии. Сайт МИЭТ не умеет искать по преподавателю, поэтому приложение собирает расписание само — по всем группам. Можно добавить в избранное звёздочкой.

![Поиск преподавателя](docs/04-teacher.jpg)

### Аудитория

Поиск по номеру помещения: `8109`, `1201 м`. Показывает, кто и когда занимает аудиторию. Кнопка **«Показать свободные»** — только свободные сейчас.

![Аудитории](docs/05-audience.jpg)

## Без интернета

Расписание загружается один раз и хранится на телефоне. Без сети показывает то, что уже сохранено.

## Напоминания

За 1, 5, 10 или 15 минут до начала пары. Включаются в «Настройках», работают без интернета. После перезагрузки телефона восстанавливаются сами.

## Если что-то не работает

Кнопка **«Сообщить об ошибке»** — «Настройки» → «О программе». Сама соберёт версию приложения и состояние данных в письмо.
